# form-analysis-c · 数据分析 C 题交付脚本

数据分析竞赛 C 题的全流程交付脚本：从数据预处理、第一问建模，到多问求解、文档生成与结果核验。

## 内容

| 文件/目录 | 说明 |
|---|---|
| `preprocess_and_q1.py` | 数据预处理与第一问建模 |
| `export_q1.mjs` | 第一问结果导出 |
| `finalize_delivery.py` | 交付包整理 |
| `inspect_materials.py` / `inspect_user_doc.py` | 材料与文档检查 |
| `重新核验/` | 问题 2 核验脚本（solve / analyze / make_docs / package_results 等） |
| `问题3终端修订/` | 问题 3 修订脚本（build_doc / revise / summarize 等） |
| `全题解析与第一问建模.md` | 建模思路说明 |
| `文件清单.md` | 交付文件清单 |

## 说明

- 交付文档（docx/pdf）与打包文件未包含在本仓库。
- 数据文件未包含；代码中标注了所需数据结构。
