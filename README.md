# analysis-delivery-toolkit · 数据分析交付工具链

数据分析项目的全流程交付脚本：从数据预处理、建模求解，到文档生成与结果核验，一键产出可复现的交付物。

## 内容

| 文件/目录 | 说明 |
|---|---|
| `preprocess_and_q1.py` | 数据预处理与首问建模 |
| `export_q1.mjs` | 结果导出 |
| `finalize_delivery.py` | 交付包整理 |
| `inspect_materials.py` / `inspect_user_doc.py` | 材料与文档检查 |
| `重新核验/` | 结果核验脚本（求解、分析、文档生成、打包） |
| `问题3终端修订/` | 修订脚本（文档构建、修订、汇总） |
| `全题解析与第一问建模.md` | 建模思路说明 |
| `文件清单.md` | 交付文件清单 |

## 说明

- 交付文档与数据文件未包含在本仓库；代码中标注了所需数据结构。
